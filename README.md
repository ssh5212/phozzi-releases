# PHOZZI (뽀찌)

작업하는 화면 한편의 작은 친구.

- 홈페이지: https://phozzi.angelplayer.net
- Windows 10/11 x64 설치 파일은 Releases의 `PHOZZI-Setup.exe`를 사용하세요.
- 기존 사용자도 같은 Google 또는 Kakao 계정으로 로그인하면 기존 데이터를 이어서 이용할 수 있습니다.
- 설치판은 서명을 확인한 업데이트를 준비하고 다음 실행 때 적용합니다.

이 저장소는 공식 설치 파일과 업데이트 패키지 배포용입니다.
프로그램 원본 소스, 운영 설정, 계정 데이터, 업데이트 서명 개인 키는 포함하지 않습니다.
